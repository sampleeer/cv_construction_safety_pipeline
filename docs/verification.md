## Качество модели

[Полные test-метрики](helmet-quality-local.json). Test: 96 изображений.

| Класс | Precision | Recall | mAP50 |
|---|---:|---:|---:|
| helmet | 0.918 | 0.791 | 0.860 |
| no_helmet | 0.286 | 0.160 | 0.145 |
| person | 0.779 | 0.876 | 0.876 |

Общий mAP50: **0.627**, mAP50–95: **0.331**.
Класс no_helmet пока слабый: recall 0.16. Этот артефакт маркируется experimental,
полный gate (recall >= 0.6) он не проходит. Демо-пороги нулевые и подтверждают только
возможность сквозного запуска, а не пригодность контроля.

Recall отчёта рассчитан при выбранной Ultralytics рабочей точке и не равен recall
API при confidence=0.4. Нужны полное обучение, калибровка на val и новый независимый
тест на видео с целевой камеры. Промышленное качество не заявляется.
