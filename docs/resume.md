# Формулировка для резюме

**HelmetWatch — система видеоконтроля касок на стройплощадке. Самостоятельный проект.**

- Подготовил трёхклассовую выборку Construction-PPE и дообучил YOLO11n для обнаружения
  касок, голов без касок и людей; реализовал оценку по классам на отложенной выборке.
- Разработал Python API с ONNX Runtime и OpenCV-видеоклиент с ограниченной очередью
  кадров, обработкой перегрузки и временных ошибок сетевого взаимодействия.
- Реализовал IoU-трекинг областей головы и подтверждение нарушений по времени;
  добавил SQLite-журнал, снимки событий и страницу просмотра.
- Настроил DVC-пайплайн подготовки/обучения/оценки/экспорта, проверки PyTorch/ONNX,
  контейнеризацию, CI/CD и мониторинг Prometheus.

Стек: Python, FastAPI, PyTorch, YOLO11, ONNX Runtime, OpenCV, SQLite, DVC, Docker,
pytest, mypy, GitHub Actions.

Указывать как учебный прототип. Не заявлять промышленное внедрение, распознавание
личностей, GPU-ускорение, TensorRT или проверку на реальной стройплощадке.
Метрики добавлять с указанием demo-профиля, размера test и условий измерения.
